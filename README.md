# GitHub PR Line Viewed

GitHub の Pull Request の diff を「行単位」で確認済みにできる Chrome 拡張です。
GitHub 標準の Viewed はファイル単位なので、diff の大きいファイルだと
どこまで読んだか分からなくなる、という問題を埋めるためのものです。

## インストール

1. このリポジトリを clone するか ZIP で落として、任意の場所に置く

   ```bash
   git clone https://github.com/yana-gi/gh-pr-line-viewed.git
   ```

2. Chrome で `chrome://extensions` を開く
3. 右上の「デベロッパーモード」を ON にする
4. 「パッケージ化されていない拡張機能を読み込む」を押し、`gh-pr-line-viewed` フォルダ
   （`manifest.json` があるフォルダ）を選ぶ
5. PR の Files changed タブを開く。画面左下に「行ごと Viewed」パネルが出れば動作中

拡張のコードを書き換えたときは、`chrome://extensions` のカードにある更新ボタンを押し、
さらに対象のタブを再読み込みしてください。すでに開いていたタブには content script が
入らないため、インストール直後もタブの再読み込みが必要です。

対象 URL は `/pull/<番号>/files`（classic 表示）と `/pull/<番号>/changes`（新しい Files
changed 表示）の両方です。記録は PR 単位なので、どちらの URL で付けても共通で使えます。

## 設定

### 表示まわり

設定項目はすべて画面のパネル上で切り替えます。設定ファイルはありません。

| 設定 | 場所 | 既定 |
| --- | --- | --- |
| パネルの左右 | パネル右上の ◨ / ◧ | 左下 |
| パネルの折りたたみ | パネルのヘッダーをクリック | 展開 |
| 確認済みの行を隠す | パネルの「確認済みを隠す」または `⇧H` | OFF |
| スクロールで自動確認 | パネルのチェックボックス | OFF |

これらは `chrome.storage.local` に保存され、次に開いたときも維持されます。
ブラウザ単位の設定なので、別のマシンには同期されません。

### 記録の管理

ツールバーの拡張アイコンを押すと、記録が残っている PR の一覧が出ます。
PR ごとの削除と全削除ができます。特定の PR だけ消したい場合は、その PR を開いて
パネルの「このPRの記録をリセット」でも構いません。

### 権限について

使っている権限は `storage`（記録の保存）と `https://github.com/*` の 2 つだけです。
記録はローカルにのみ保存され、外部へ送信することはありません。

## トラブルシューティング

パネルが出ない場合は、まずタブを再読み込みしてください。それでも出ないときは、
URL が `/pull/<番号>/files` か `/pull/<番号>/changes` になっているか、
`chrome://extensions` で拡張が有効かつエラーが出ていないかを確認します。

パネルは出るが行数が `0/0` のままの場合は、diff がまだ読み込まれていません。
新表示ではファイルを展開した分だけが集計対象になります。

Viewed を押してもコメント欄が閉じない場合は、DevTools のコンソールで
以下を実行すると、拡張が何をしたかが分かります。

```js
document.documentElement.dataset.glvClose
```

`step` の値が判断材料です。`no-textarea` はコメント欄を見つけられていない、
`clicked-ancestor` / `clicked-global` は Cancel を押したのに閉じていない、
`esc-fallback` は Cancel 相当の要素が見つからなかった、という意味です。

## 使い方

### 新しい Files changed 表示（`/pull/<番号>/changes`）

行番号のドラッグやクリックは GitHub のコメント用範囲選択なので、拡張は奪いません。
選択すると、先頭行の行番号のすぐ左に GitHub の Viewed と同じチェックボックスが出るので、
それを押して確認済みにします。

| 操作 | 動作 |
| --- | --- |
| 行番号をドラッグ（または クリック → Shift+クリック） | GitHub の範囲選択。行番号の左に Viewed チェックボックスが現れる |
| Viewed チェックボックス | 選択範囲をまとめて確認済み。すでに全部確認済みならチェック済みで表示され、押すと解除 |
| `Esc` | チェックボックスを閉じる |

行番号の左に余白が無い行（変更のない行など）では、ラベルを省いてチェックボックスだけの
表示に切り替わります。何行が対象かはマウスを乗せるとツールチップに出ます。

チェックを付けると、その選択で開いていたコメント欄が空なら閉じます（Cancel を押します）。
何か書きかけの場合は閉じません。チェックボックス自体も引っ込み、別の範囲を選ぶとまた出ます。

コメントを付けたい時は、これまでどおり `+` ボタンを押せば通常のコメント欄が開きます。

### classic 表示（`/pull/<番号>/files`）

| 操作 | 動作 |
| --- | --- |
| 行番号をクリック | その行を確認済み / 解除 |
| Shift + 行番号クリック | 直前にクリックした行からの範囲をまとめて設定 |
| Alt / Cmd / Ctrl + 行番号クリック | GitHub 標準の「その行へのリンク」（拡張は何もしない） |

### 共通

| 操作 | 動作 |
| --- | --- |
| `⇧N` | 次の未確認行までスクロール |
| `⇧H` | 確認済みの行を隠す / 表示（残りだけを読める） |
| ファイル名の横の `全部` / `解除` | そのファイルの全行をまとめて設定 |
| パネルの「スクロールで自動確認」 | 画面上端を通過した行を自動で確認済みにする（既定 OFF） |
| パネルの「このPRの記録をリセット」 | この PR の記録を全削除 |
| パネル右上の ◨ / ◧ | パネルを左下 / 右下に移動（既定は左下） |
| パネルのヘッダー | クリックで折りたたみ |

確認済みの行は薄く表示され、行番号の左に緑のバーと ✓ が付きます。
進捗はファイル名の横（`12 / 42 行`）と画面下のパネル（PR 全体）に出ます。

ツールバーの拡張アイコンから、記録が残っている PR の一覧・個別削除・全削除ができます。

「スクロールで自動確認」は、直前に通過した 700px 分だけを対象にします。
一気にスクロールした時に、読んでいない行まで確認済みになるのを防ぐためです。

## 記録のしくみ

- 保存先は `chrome.storage.local`（ローカルのみ。外部送信はしません）
- キーは PR ごと・ファイルごと・行ごと。行の識別子は行番号ベースです
  - `D123` = 削除側の 123 行目 / `A123` = 追加側の 123 行目 / `C12-15` = 変更のない行
  - 左右のサイド単位で持つため、Unified / Split を切り替えても記録は一致します
  - classic 表示と新しい Files changed 表示でもキーは共通です（表示を切り替えても引き継がれます）
- 記録は 80 PR 分まで保持し、古いものから自動で消えます
- PR に新しい commit が積まれて行番号がずれると、記録もずれます。
  その場合はパネルの「このPRの記録をリセット」で消してください

## 対応表示

classic（`table.diff-table`）と新しい Files changed（`tr.diff-line-row`）の両方に対応しています。
DOM の違いは `content.js` の `CLASSIC` / `NEXT` アダプタで吸収していて、
`adapter()` がページを見て自動で切り替えます。

新表示では diff が遅延読み込みされるため、ファイルを展開した分だけが集計対象になります。

## 制限

- GitHub の DOM 変更に追従が必要です。表示が崩れたり反応しなくなった場合は
  `content.js` のアダプタ（セレクタ定義）を直してください
- github.com のみが対象です
- PR に新しい commit が積まれて行番号がずれると、記録もずれます

## 開発

`test/` に GitHub の diff DOM を再現したフィクスチャがあります。

```bash
cd test && python3 -m http.server 8766
```

ブラウザで `http://127.0.0.1:8766/o/r/pull/123/files/` を開くと、
`chrome.storage` をスタブした状態で content script の動作を確認できます。
コンソールから以下で表示形式を切り替えられます。

- `renderUnified()` / `renderSplit()` … classic 表示
- `renderNextUnified()` / `renderNextSplit()` … 新しい Files changed 表示
